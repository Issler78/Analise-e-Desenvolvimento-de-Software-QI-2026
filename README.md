# Análise e Desenvolvimento de Software

Este é um projeto educacional de final de disciplina (Análise e Desenvolvimento de Software) da QI Faculdade & Escola Técnica, do curso Técnico em Informática para Internet.
O projeto foi desenvolvido com base nas aulas da professora Andreza Barcaro, em dupla com meu colega de turma Pedro Maggi.

---

## O que é o projeto?
Antes de tudo, definimos um nome para um software de uma escola fictícia, **SKILLIFY**.
O Skillify é o protótipo de um software escalar e confiável, que centralizaria e automatizaria os processos de uma escola de cursos, como o controle de alunos, notas, frequência e documentos, tornando a gestão escolar mais eficiente, segura e confiável. 

Importante ressaltar, na disciplina o foco não era a construção do software (até por isso só existem os modelos e um arquivo .jsp simples), e sim as etapas até o desenvolvimento, onde aprendemos:
- Levantar requisitos funcionais e não funcionais do sistema;
- Especificar as regras de negócio;
- Modelar os BPMNs dos processos;
- Criar o diagrama UML de casos de uso e a sua especificação/documentação;
- Criar o diagrama de classes;
- Criar o modelo Entidade-Relacionamento conceitual;
- Criar o modelo Entidade-Relacionamento lógico;
- Criar o modelo físico (SQL);
- Criar as classes Java do projeto.

> [!NOTE]
> O modelo físico e as classes Java eu já possuía o conhecimento para as suas criações, mas é importante que esteja descrito como um conhecimento aprendido na disciplina.

## Softwares Utilizados
- **Bizagi Process Modeler** - para os BPMNs;
- **Astah** - para o diagrama UML de casos de uso e para o diagrama de classes;
- **BrModelo** - para os modelos conceitual e lógico;
- **NetBeans/Visual Studio Code** - para a criação das classes Java.
